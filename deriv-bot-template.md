# Deriv bot template discovery steps

1. Open the Deriv developer page for the trading app builder.
2. Confirm whether the page exposes a direct download link.
3. If it does not, search for the public template repository maintained by Deriv.
4. Verify the repository is an official template/starter.
5. Save the repo URL for cloning or for manual download.
6. Inspect the README to confirm what the template includes and how it is meant to be customized.

## Relevant repo
- https://github.com/deriv-com/trading-bot-template

## Notes
- The public builder page is a preview/login gateway, not a direct download page.
- The template repository is a white-label starter, not a finished bot product.
- Use the repository as the base if you want to modify and deploy your own bot UI.
